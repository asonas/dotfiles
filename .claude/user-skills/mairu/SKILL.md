# mairu CLI の実行

mairu CLI を実行する際は、必ず `--no-login` オプションを付ける。

```
mairu exec --no-login -- <command>
```

このオプションにより、ログインが必要な場面で対話的プロンプトが表示されず即座にエラー終了する。エージェントがログインプロンプトでブロックされるのを防ぐため。
